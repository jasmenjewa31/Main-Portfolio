# Maitreyi — Brand Partnership Portfolio

A burgundy and champagne portfolio concept for fashion, beauty, UGC and brand partnerships. Includes the floral MR signature, responsive layouts, animated backgrounds, visual portfolio and demo enquiry form.

## Files
- `index.html` — page content and layout
- `assets/css/` — styles; the latest refinements are in partnerships.css
- `assets/js/` — interactions and motion
- `assets/images/` — photographs and branding artwork
- `.nojekyll` — serves the static files directly on GitHub Pages

## Upload to GitHub
1. Extract this ZIP on your computer.
2. Create a GitHub repository, then upload the extracted contents. Keep index.html at the repository root, alongside assets and this README. Do not upload the ZIP itself as the website.
3. Open repository Settings → Pages.
4. Under Build and deployment choose Deploy from a branch, select main and /(root), then Save.
5. Once deployment completes, open the site address shown on that page.

Official publishing guide: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Preview locally
No build or installation is required. Open index.html for a quick preview, or serve this folder with a static web server. Fonts load from Google Fonts and require an internet connection.

## Demo behaviour
The enquiry form previews and downloads a brief; it does not send email or store submissions. This is a mock design using supplied imagery of Maitreyi Ramakrishnan, not an official website or representation. No audience metrics, brand affiliations or campaign results are claimed. No third-party image rights are granted by this package.

## Editing
Keep the stylesheet order in index.html. All assets use relative paths for compatibility with GitHub project sites. The package excludes local server logs, previous exports and working scripts.
