# Creative Portfolio Malaysia

This folder contains a browser-ready HTML, CSS, and JavaScript portfolio concept for the Malaysian market.

## Preview

Open `index.html` directly from this folder. The page is self-contained and does not need online React, Tailwind, or Babel links to display.

## Areas Included

- Industrial website portfolio
- Freelancer sites
- Skin care
- Fashion retail shops
- Pilates, yoga, and gym
- Dental
- Content creators
- TikTok portfolio style website

## Items That Need Your Approval Later

- Final animated header asset: MP4 or WebM is recommended over GIF for smoother mobile loading.
- Final brand name, contact email, WhatsApp number, and social links.
- Whether the copy should stay English-only or become bilingual for Malaysia, for example English and Bahasa Malaysia.
- Whether to convert this local prototype into a production React/Tailwind build later.
