# ELARA — The Shape of a Memory

Responsive, standalone couture website concept. Open `index.html` directly, or run `node server.cjs` and visit http://127.0.0.1:4174.

Includes scroll-linked cinematic imagery, an embroidered-thread transition, collection details with next/previous navigation, enlarged fabric inspection, mobile menu, reduced-motion support, and an appointment request draft stored locally. No booking is transmitted; commerce and appointment service connections are not configured.

Images in `assets/` were created with the built-in image generation tool. Fonts load from Google Fonts with local serif/sans-serif fallbacks. All other assets and interactions are local.

Image prompt set: (1) Photorealistic champagne embroidered couture gown, adult South Asian model on right, dark studio and silk train, left negative space. (2) Four equal-width photographic panels of full-length adult models wearing burgundy, champagne, black, and ivory couture in a warm stone atelier, no text. (3) Burgundy couture model on right in monumental stone palace, train extending to left, cinematic chiaroscuro, no text.

Atelier image update: `assets/atelier-satin.png`, generated with the built-in image tool. Prompt: photorealistic vertical couture portrait of an adult olive-skinned model with a short dark wavy bob in rear three-quarter view looking left, pearl taupe silk satin gown with thin straps and a deep draped cowl open back, flowing skirt, warm dark studio, soft golden side light, centered subject and generous headroom for curved framing, no text or logos.
